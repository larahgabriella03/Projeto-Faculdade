
# 💻 Projeto de Extensão — Desenvolvimento de Software

## 📌 Sobre o Projeto

Este repositório reúne as atividades desenvolvidas no Projeto de Extensão em Desenvolvimento de Software.

O objetivo é aplicar, de forma prática, conhecimentos de desenvolvimento web, lógica de programação em linguagem C e modelagem de banco de dados, por meio da criação de uma empresa fictícia e da simulação de suas operações.

O projeto está dividido em quatro etapas principais:

1. Estrutura Organizacional
2. Desenvolvimento de Site Institucional
3. Desenvolvimento de Sistema em Linguagem C
4. Modelagem e Implementação de Banco de Dados

## 🌐 2. Desenvolvimento do Site Institucional

O projeto contempla o desenvolvimento de um site institucional que representa a presença digital da empresa.

O site deverá disponibilizar informações sobre o negócio, seus produtos ou serviços e seus canais de atendimento.

### 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação e organização das páginas.
- **CSS3:** Estilização, identidade visual e layout.

### 📄 Páginas Obrigatórias

O site deverá conter, no mínimo, cinco páginas interligadas por um menu de navegação.

| Página | Descrição |
|--------|-----------|
| Home | Apresentação inicial da empresa |
| Sobre a Empresa | História, missão, visão e valores |
| Produtos ou Serviços | Apresentação das soluções oferecidas |
| Contato | Informações e canais de atendimento |
| Portfólio ou Projetos | Demonstração dos trabalhos realizados |

### Requisitos

- Estruturação adequada das páginas em HTML.
- Estilização e organização visual com CSS.
- Menu de navegação entre todas as páginas.
- Conteúdo claro e organizado.
- Utilização exclusiva de HTML e CSS.

## 🗄️ 4. Modelagem e Implementação do Banco de Dados

Esta etapa contempla a criação de um banco de dados relacional para representar as informações necessárias ao funcionamento da empresa.

### Diagrama Entidade-Relacionamento (DER)

Será desenvolvido um DER contendo:

- No mínimo cinco entidades (tabelas).
- Atributos de cada entidade.
- Identificação das chaves primárias (PK).
- Identificação das chaves estrangeiras (FK).
- Relacionamentos entre as entidades.
- Cardinalidades dos relacionamentos.

### Implementação SQL

O banco de dados será implementado utilizando um SGBD escolhido pelo grupo.

**SGBD:** [MySQL]

A implementação deverá contemplar:

- Criação de tabelas (`CREATE TABLE`).
- Definição de chaves primárias (`PRIMARY KEY`).
- Definição de chaves estrangeiras (`FOREIGN KEY`).
- Tipos de dados apropriados.
- Relacionamentos entre as tabelas.
- Inserção de dados de exemplo (`INSERT INTO`).
- Consultas aos dados (`SELECT`).

### Arquivos SQL

Os scripts serão disponibilizados na pasta `banco-de-dados`, juntamente com o diagrama DER.
